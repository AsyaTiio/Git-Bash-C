# Bash — справочник (базовые команды)

Обобщённые команды терминала Linux/macOS. Пополняем по мере встречи.

**Shell-скрипты (`.sh`)** — [SHELL_СКРИПТЫ_СПРАВОЧНИК.md](SHELL_СКРИПТЫ_СПРАВОЧНИК.md)  
**Язык C (`.c`)** — [C_СПРАВОЧНИК.md](C_СПРАВОЧНИК.md)

## Как пополнять

1. Найди раздел или создай новый.
2. Добавь строку: **команда → зачем → пример**.
3. Запиши в **Журнал** внизу, что добавил.

## Навигация

| Команда     | Зачем                                  | Пример   |
| ----------- | -------------------------------------- | -------- |
| `pwd`       | Текущая директория                     | `pwd`    |
| `cd <путь>` | Перейти в папку                        | `cd src` |
| `cd ..`     | На уровень вверх                       | `cd ..`  |
| `cd ~`      | Домашняя директория                    | `cd ~`   |
| `cd -`      | Вернуться в предыдущую папку           | `cd -`   |
| `ls`        | Список файлов                          | `ls`     |
| `ls -l`     | Подробный список (права, размер, дата) | `ls -l`  |
| `ls -la`    | Включая скрытые файлы (`.имя`)         | `ls -la` |
| `ls -lh`    | Размеры в человекочитаемом виде (K, M) | `ls -lh` |

## Файлы и папки

| Команда                | Зачем                                  | Пример                   |
| ---------------------- | -------------------------------------- | ------------------------ |
| `mkdir <имя>`          | Создать папку                          | `mkdir logs`             |
| `mkdir -p a/b/c`       | Создать вложенные папки                | `mkdir -p src/utils`     |
| `touch <файл>`         | Создать пустой файл / обновить время   | `touch notes.txt`        |
| `cp <откуда> <куда>`   | Копировать                             | `cp file.txt backup.txt` |
| `cp -r <папка> <куда>` | Копировать папку рекурсивно            | `cp -r src src_backup`   |
| `mv <откуда> <куда>`   | Переместить или переименовать          | `mv old.txt new.txt`     |
| `rm <файл>`            | Удалить файл                           | `rm temp.log`            |
| `rm -r <папка>`        | Удалить папку и содержимое             | `rm -r cache`            |
| `rm -rf <папка>`       | Удалить без подтверждений (осторожно!) | `rm -rf build`           |

## Просмотр содержимого

| Команда | Зачем | Пример |
|---------|-------|--------|
| `cat <файл>` | Вывести файл целиком | `cat config.conf` |

| `wc -l <файл>` | Количество строк | `wc -l data.txt` |
| `wc -c <файл>` | Количество байт | `wc -c data.txt` |

## Права и выполнение

| Команда | Зачем | Пример |
|---------|-------|--------|
| `chmod +x <файл>` | Разрешить запуск (execute) | `chmod +x script.sh` |
| `chmod 755 <файл>` | Права в числовом виде (rwxr-xr-x) | `chmod 755 run.sh` |
| `chmod -R +x <папка>` | Рекурсивно для папки | `chmod -R +x scripts/` |

**Расшифровка `ls -l`:** `r` — чтение, `w` — запись, `x` — выполнение. Три группы: владелец / группа / остальные.

## Процессы

| Команда | Зачем | Пример |
|---------|-------|--------|
| `ps` | Список процессов текущей сессии | `ps` |
| `ps aux` | Все процессы, подробно | `ps aux` |

## Поиск

| Команда | Зачем | Пример |
|---------|-------|--------|
| `find <путь> -name "<шаблон>"` | Найти файлы по имени | `find . -name "*.log"` |
| `find <путь> -type f` | Только файлы | `find src -type f` |
| `find <путь> -type d` | Только папки | `find . -type d` |
| `grep <текст> <файл>` | Найти строку в файле | `grep ERROR app.log` |
| `grep -r <текст> <папка>` | Рекурсивный поиск в папке | `grep -r "TODO" src/` |
| `grep -i <текст> <файл>` | Без учёта регистра | `grep -i error log.txt` |
| `grep -n <текст> <файл>` | С номерами строк | `grep -n main main.c` |

## Перенаправление и пайпы

| Конструкция | Зачем | Пример |
|-------------|-------|--------|
| `cmd > file` | Вывод в файл (перезапись) | `ls > list.txt` |
| `cmd >> file` | Дописать в конец файла | `echo "ok" >> log.txt` |
| `cmd 2> file` | Ошибки (stderr) в файл | `./script.sh 2> err.log` |
| `cmd > file 2>&1` | Всё (stdout + stderr) в один файл | `make > build.log 2>&1` |
| `cmd1 \| cmd2` | Передать вывод первой команде во вторую | `cat file \| grep hello` |
| `echo "text"` | Вывести текст | `echo "Hello"` |
| `echo "text" > file` | Записать строку в файл | `echo "line" > out.txt` |

## Компиляция C (gcc)

| Команда | Зачем | Пример |
|---------|-------|--------|
| `gcc -std=c11 file.c -o prog` | Скомпилировать C11 | `gcc -std=c11 src/hello.c -o hello` |
| `gcc ... -Wall -Werror -Wextra` | Строгие предупреждения | как на бассейне |
| `gcc ... -lm` | Математика (`math.h`) | `gcc src/f.c -o f -lm` |
| `./prog` | Запустить бинарник | `./hello` |
| `echo $?` | Код возврата программы | `0` = ok |

Проверка с вводом:

```bash
echo "8 2" | ./arithmetic
```

Подробнее про C: [C_СПРАВОЧНИК](C_СПРАВОЧНИК.md).

| Редактор | Открыть | Сохранить | Выйти |

### Vim — базовые команды

| Команда | Режим | Зачем |
|---------|-------|-------|
| `i` | normal → insert | вставка текста |
| `Esc` | insert → normal | выйти из режима ввода |
| `h` `j` `k` `l` | normal | курсор влево/вниз/вверх/вправо |
| `gg` | normal | в начало файла |
| `G` | normal | в конец файла |
| `0` | normal | начало строки |
| `$` | normal | конец строки |
| `dd` | normal | удалить строку |
| `u` | normal | отменить |
| `:w` | command | сохранить |
| `:q` | command | выйти |
| `:wq` | command | сохранить и выйти |
| `:q!` | command | выйти без сохранения |
| `:%s/old/new/g` | command | заменить во всём файле |

## Термины

| Термин | Смысл |
|--------|--------|
| Shell | Оболочка командной строки (bash, sh, zsh) |
| Bash | Bourne Again Shell — распространённая оболочка |
| STDOUT | Стандартный вывод (обычно экран) |
| STDERR | Поток ошибок |
| PID | ID процесса |
| Shebang | `#!/bin/bash` в первой строке скрипта |
| Pipe (`\|`) | Передача вывода одной команды на вход другой |
| Фон (`&`) | Процесс работает, не блокируя терминал |
