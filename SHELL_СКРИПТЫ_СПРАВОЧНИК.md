## Shell-скрипт vs C

| | Shell (`.sh`) | C (`.c`) |
|---|---------------|----------|
| Тип | Интерпретируемый | Компилируемый |
| Запуск | `bash script.sh` / `./script.sh` | `gcc file.c -o prog` → `./prog` |
| Первая строка | `#!/bin/bash` | `#include <stdio.h>` |
| На бассейне | T01D01, T02D02… | Позже, отдельные дни |

## Анатомия `.sh` файла

```bash
#!/bin/bash
# Комментарий — пояснение, не выполняется

VAR="значение"          # переменная
echo "$VAR"             # вывод

if [ условие ]; then
  команды
fi

exit 0                  # 0 = успех, не 0 = ошибка
```

| Элемент | Зачем |
|---------|--------|
| `#!/bin/bash` | Shebang — какой интерпретатор запускать |
| `#` | Комментарий |
| `VAR="..."` | Переменная (без пробелов вокруг `=`) |
| `"$VAR"` | Подстановка значения (кавычки — от пробелов в пути) |
| `exit N` | Код возврата для ОС и автотестов |

## Создание и запуск

```bash
vim src/edit.sh          # создать/редактировать
chmod +x src/edit.sh     # право на выполнение
./src/edit.sh arg1 arg2  # запуск из текущей папки
bash src/edit.sh arg1    # явно через bash (chmod не обязателен)
```

| Команда | Зачем |
|---------|--------|
| `chmod +x file.sh` | Разрешить `./file.sh` |
| `./script.sh` | Запуск (нужен `+x` и путь `./`) |
| `bash script.sh` | Запуск через интерпретатор |
| `./script.sh &` | Фоновый запуск |

## Аргументы командной строки

| Переменная | Смысл | Пример: `./edit.sh a.txt old new` |
|------------|--------|-----------------------------------|
| `$0` | Имя скрипта | `./edit.sh` |
| `$1` | 1-й аргумент | `a.txt` |
| `$2` | 2-й аргумент | `old` |
| `$3` | 3-й аргумент | `new` |
| `$#` | Количество аргументов | `3` |
| `$@` | Все аргументы списком | — |
| `$?` | Код возврата **последней** команды | `0` если ok |

Проверка числа аргументов:

```bash
if [ $# -ne 3 ]; then
  echo "Usage: $0 <file> <old> <new>"
  exit 1
fi

FILE="$1"
OLD="$2"
NEW="$3"
```

**Пояснение:** всегда бери аргументы в кавычки: `"$FILE"` — иначе пути с пробелами сломаются.

## Переменные

```bash
NAME="Ivan"
echo "Hello, $NAME"
echo "Hello, ${NAME}!"    # явные границы переменной

COUNT=0
COUNT=$((COUNT + 1))      # арифметика
COUNT=$[ COUNT + 1 ]        # старый стиль (тоже работает)
```

| Конструкция | Зачем |
|-------------|--------|
| `VAR=value` | Присвоить (без пробелов!) |
| `"$VAR"` | Использовать значение |
| `${VAR}` | То же, удобно рядом с текстом |
| `$((выражение))` | Целочисленная математика |
| `export VAR=1` | Переменная для дочерних процессов |

## Условия: `if` и `test` (`[` `]`)

```bash
if [ -f "$FILE" ]; then
  echo "файл есть"
elif [ ! -f "$FILE" ]; then
  echo "файла нет"
  exit 1
else
  echo "другое"
fi
```

### Частые проверки

| Тест | Значение |
|------|----------|
| `[ -f file ]` | файл существует |
| `[ -d dir ]` | каталог существует |
| `[ -x file ]` | исполняемый |
| `[ -z "$STR" ]` | строка пустая |
| `[ -n "$STR" ]` | строка не пустая |
| `[ "$A" = "$B" ]` | строки равны |
| `[ "$A" != "$B" ]` | строки не равны |
| `[ $# -eq 3 ]` | ровно 3 аргумента |
| `[ $# -ne 3 ]` | не 3 аргумента |
| `[ $? -eq 0 ]` | предыдущая команда успешна |

### Числовые сравнения

| Оператор | Смысл |
|----------|--------|
| `-eq` | равно |
| `-ne` | не равно |
| `-lt` | меньше |
| `-gt` | больше |

### Логика

```bash
if [ -f "$FILE" ] && grep -qF "$OLD" "$FILE"; then
  echo "ok"
fi

if [ ! -f "$FILE" ]; then
  exit 1
fi
```

| Символ | Смысл |
|--------|--------|
| `&&` | И (вторая команда, если первая ok) |
| `\|\|` | ИЛИ |
| `!` | отрицание |

## Циклы

### `for`

```bash
for file in *.log; do
  echo "$file"
done

for i in 1 2 3; do
  echo "$i"
done

for i in {1..5}; do
  echo "part${i}.key"
done
```

### `while` (читать файл построчно)

```bash
while IFS= read -r line; do
  echo "$line"
done < input.txt
```

### `while true` (бесконечный цикл)

```bash
while true; do
  echo "tick"
  sleep 1
done
```

Используется в заданиях типа «фоновый модуль» — останавливается через `kill`.

## Коды возврата: `exit`

| Код | Обычно |
|-----|--------|
| `0` | Успех |
| `1` (и др.) | Ошибка |

```bash
if ! grep -qF "$OLD" "$FILE"; then
  echo "Substring not found"
  exit 1
fi

exit 0
```

**Пояснение:** автотесты смотрят `$?` после запуска скрипта. Явный `exit 1` при ошибке — хорошая практика.

## Команды внутри скриптов

### `grep`

| Команда | Зачем |
|---------|--------|
| `grep "text" file` | Найти строку |
| `grep -qF "text" file` | Тихо: только код возврата (удобно в `if`) |
| `grep -qF "$OLD" "$FILE"` | Есть ли подстрока в файле |

`-F` — искать как обычный текст, не regex.

### `sed` (замена в файле)

```bash
# Linux: изменить файл на месте
sed -i 's/old/new/g' "$FILE"

# Только вывести результат (не менять файл)
sed 's/old/new/g' "$FILE"
```

| Флаг | Смысл |
|------|--------|
| `s/old/new/g` | substitute: заменить все вхождения |
| `-i` | edit in-place (перезаписать файл) |
| `g` | global — все вхождения в строке |

**Пояснение:** если в `old`/`new` есть `/`, используй другой разделитель: `sed 's|a/b|c/d|g'`.

### `awk` (разбор полей)

```bash
# первое поле каждой строки
awk '{print $1}' files.log

# разделитель поля — дефис
awk -F'-' '{print $1}' files.log

# подсчёт в awk
awk -F'-' '{ paths[$1]++; } END { print length(paths) }' files.log
```

| Параметр | Смысл |
|----------|--------|
| `-F'-'` | поле разделяется `-` |
| `$1`, `$NF` | первое / последнее поле |
| `END { }` | блок после обработки всех строк |

### Подстановка вывода команды

```bash
SIZE=$(stat -c %s "$FILE")
HASH=$(sha256sum "$FILE" | awk '{print $1}')
DT=$(date "+%Y-%m-%d %H:%M:%S")
```

`$(команда)` — взять stdout команды в переменную.

## Логирование (SHA, размер, дата)

Типичный формат на бассейне (T02D02):

```text
путь-размер_байт-дата время-SHA256-SHA-256
```

Функция для дописи в лог:

```bash
log_change() {
  local file="$1"
  local size
  size=$(stat -c %s "$file")
  local dt
  dt=$(date "+%Y-%m-%d %H:%M:%S")
  local hash
  hash=$(sha256sum "$file" | awk '{print $1}')
  echo "${file}-${size}-${dt}-${hash}-SHA-256" >> src/files.log
}
```

| Команда | Зачем |
|---------|--------|
| `stat -c %s file` | размер в байтах (Linux) |
| `date "+%Y-%m-%d %H:%M:%S"` | дата/время |
| `sha256sum file` | хеш SHA-256 |
| `>> file` | дописать в конец (не перезаписать) |

## Функции

```bash
#!/bin/bash

my_func() {
  local arg="$1"
  echo "Got: $arg"
}

my_func "hello"
```

| Элемент | Зачем |
|---------|--------|
| `name() { }` | объявление функции |
| `local var` | локальная переменная (не портит глобальные) |
| `$1` внутри функции | аргумент функции |

## Шаблон: скрипт с аргументами (как `edit.sh`)

```bash
#!/bin/bash

# 1. Проверка аргументов
if [ $# -ne 3 ]; then
  echo "Usage: $0 <file> <old> <new>"
  exit 1
fi

FILE="$1"
OLD="$2"
NEW="$3"

# 2. Проверка файла
if [ ! -f "$FILE" ]; then
  echo "File not found"
  exit 1
fi

# 3. Проверка подстроки
if ! grep -qF "$OLD" "$FILE"; then
  echo "Substring not found"
  exit 1
fi

# 4. Действие
sed -i "s/$(printf '%s' "$OLD" | sed 's/[\/&]/\\&/g')/$(printf '%s' "$NEW" | sed 's/[\/&]/\\&/g')/g" "$FILE"

# 5. Лог
SIZE=$(stat -c %s "$FILE")
DT=$(date "+%Y-%m-%d %H:%M:%S")
HASH=$(sha256sum "$FILE" | awk '{print $1}')
echo "${FILE}-${SIZE}-${DT}-${HASH}-SHA-256" >> src/files.log

exit 0
```

## Шаблон: анализатор лога (как `log_analyzer.sh`)

```bash
#!/bin/bash

if [ $# -ne 1 ]; then
  exit 1
fi

LOG="$1"

if [ ! -f "$LOG" ]; then
  exit 1
fi

total=$(wc -l < "$LOG" | tr -d ' ')
unique=$(awk -F'-' '{print $1}' "$LOG" | sort -u | wc -l | tr -d ' ')

# сколько раз менялся хеш у того же пути
hash_changes=$(awk -F'-' '
{
  path=$1
  hash=$(NF-1)
  if (path in last && last[path] != hash) count++
  last[path]=hash
}
END { print count+0 }
' "$LOG")

echo "$total $unique $hash_changes"
```

**Пояснение:** вывод — **только** три числа через пробел, без лишнего текста (требование автотестов).

## Перенаправление в скриптах

| Конструкция | Зачем |
|-------------|--------|
| `>> log.txt` | дописать stdout в файл |
| `> log.txt` | перезаписать файл |
| `2> err.log` | stderr в файл |
| `&> all.log` | stdout + stderr вместе |
| `\| awk ...` | передать вывод в следующую команду |

---

## Частые ошибки

| Ошибка | Как правильно |
|--------|----------------|
| `VAR = "x"` | `VAR="x"` (без пробелов) |
| `if [$# -eq 3]` | `if [ $# -eq 3 ]` (пробелы после `[`) |
| `./script.sh` без chmod | `chmod +x` или `bash script.sh` |
| забыли кавычки `"$FILE"` | пути с пробелами ломаются |
| `exit` без кода при ошибке | `exit 1` |
| лишний `echo` в анализаторе | только требуемый вывод |
| Windows-переносы CRLF | файл должен быть LF (на Linux) |

## Термины

| Термин | Смысл |
|--------|--------|
| Shebang | `#!/bin/bash` — строка 1 |
| Interpreter | Программа, выполняющая скрипт построчно |
| Argument | Аргумент (`$1`, `$2`…) |
| Return code / exit code | Число 0–255 после `exit` |
| STDIN / STDOUT / STDERR | Ввод / вывод / ошибки |
| Pipe | `\|` — цепочка команд |
| Here document | `<<EOF` … `EOF` — многострочный ввод |
| Edge case | Граничный случай (нет файла, 0 аргументов…) |
