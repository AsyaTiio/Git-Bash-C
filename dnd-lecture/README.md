## Быстрый старт

1. Распечатайте **листы персонажа** (по 1 на участника + запас)
2. Распечатайте **шпаргалки** (по 1 на стол)
3. Опционально: **карточки характеристик** (разрежьте, раздайте)
4. Откройте **План лекции** и ведите по таймингу
5. На этапе создания персонажа следуйте **Инструкции**

## Печать HTML-файлов

Откройте `.html` файл в браузере → `Ctrl+P` (или `Cmd+P`) → Печать.

- Лист персонажа — формат A4, портретная ориентация
- Шпаргалка — A4, альбомная ориентация
- Карточки — A4, портретная, разрезать по пунктирным линиям

## Рекомендации для укладывания в 40 минут

- Используйте **стандартный набор** характеристик: 15, 14, 13, 12, 10, 8
- Ограничьте выбор: 4 класса (Воин, Плут, Волшебник, Жрец) и 4 расы (Человек, Эльф, Дварф, Полурослик)
- Не тратьте время на броски кубиков и покупку снаряжения

## Структура занятия

```
0–8 мин    Что такое D&D
8–10 мин   Мастер и игроки
10–12 мин  Обзор листа персонажа
12–32 мин  Создание персонажа (пошагово)
32–38 мин  Имя, история, черты
38–40 мин  Итоги
```
